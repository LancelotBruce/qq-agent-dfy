# 回忆检索（memory-recall）

给机器人补一个「回忆往事」的工具：她说得出很久以前群里/私聊里聊过的事，而不是每次都靠最近 80 条上下文硬猜。

## 它怎么工作

- 读 `conversation-memory` 插件（分层会话记忆）产出的**长时记忆块**：`data/memory-v2/chunks/hour_*.json`，每小时一块，含 `title / summary / keywords / snippets`。
- 模型调用 `memory_recall` 时才会扫盘：按关键词（英文按词、中文按词 + 相邻二字）匹配 `keywords / title / summary / snippets` 打分，按分数 + 时间排序，返回前 N 块。
- **日期/时段直查**（v1.1.2）：`query` 里写「10月15日下午」「前天」「3天前」「10-15」「下午3点」会解析成 `dayKey` + 时段过滤，直接框到那几块，而不是当关键词去搜。
- **泛词忽略 + IDF 加权**（v1.1.2）：`聊天 / 下午 / 什么 / 记得` 这类词不参与检索；在某段时间的块里出现超过 60% 的词视为泛词忽略，其余词按 `1+ln((N+1)/(df+1))` 加权，人名、梗这类稀有词权重自然更高。
- **外号展开**（v1.1.3）：读 `data/member-aliases.json`（member-aliases 插件维护的外号表，`{"aliases":{"<QQ号>":["外号",…]}}`）。query 里写的是群里平时叫的外号，会自动展开成同组的真名/其他叫法一起搜；没有这个文件就静默跳过。查人时还会匹配「这几条是谁说的」（snippet 的说话人），方便问「谁说过…」。
- **平常不进提示词、不读盘、不花 token**；只有被调用时读一次（几十块 ≈ 1.8 MB，几毫秒）。
- 没命中就返回「没翻到」，让模型如实说想不起来，而不是编。

## 依赖

- 需要 `conversation-memory` 插件在运行（它负责把聊天巩固成小时块）。没装/没开时，工具会返回「没有找到长时记忆」，不会报错。
- 外号展开是可选的：有 `data/member-aliases.json`（member-aliases 插件写的）就展开，没有就不展开。
- 不需要联网、不需要任何权限（`permissions: []`）。

## 参数

| 参数 | 说明 |
| --- | --- |
| `query` | 必填。关键词 / 人名 / 话题 / 短句，越具体越准；也可以带日期（「10月15日下午」「前天 韩国银行」） |
| `days` | 可选。往回看多少天，默认取设置里的 30；`0` = 不限。query 里写了日期时以日期为准 |
| `limit` | 可选。最多返回几块，默认 5，最大 20 |

## 设置项（控制台 → 技能 → 回忆检索）

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 默认回看天数 | 30 | 模型没指定 `days` 时用这个；0 = 不限 |
| 默认返回块数 | 5 | 一次最多给几块 |
| 每块显示几条原文 | 3 | 每条截断 140 字，调大更贵 |
| 最多扫描块数 | 4000 | 从最新往旧扫 |
| 单块文件上限（KB） | 512 | 超过跳过，防异常大文件 |

## 安装

压缩包里要有 `skill.json`（放根目录最省事，套一层 `memory-recall/` 也认）：

```
memory-recall/
  skill.json
  index.js
  README.md
```

在控制台「技能市场 / 技能 → 安装本地包」选择 zip 即可；也可以把整个 `memory-recall/` 目录放进 `<应用目录>/skills/`（会热加载）。

## 数据目录

优先级：`QQ_AGENT_DATA_DIR` 环境变量 → `<应用目录>/data` / `<应用目录>/data-*/`（找第一个存在 `memory-v2/chunks` 的）。所以自定义 profile 也能用。

## 已知边界

- 块是**抽取式摘要**（插件把消息行拼起来），不是模型总结；里面有什么就能查到什么，不含语音/图片内容。
- 词面匹配、不是语义检索：同义词、指代（「那家伙」）匹配不到，建议用具体人名/名词；词都太泛时会提示「换个具体的人名、梗或事」，也可以直接写日期。
- 时间粒度到小时：块按会话每小时一块，某个小时没聊就是空的（写了「下午3点」但 15 点没块时，会自动放宽到整天并说明）。
- 聊天很多时块会很多（每小时 1 块/会话），`maxChunkFiles` 决定扫多少；只扫最新的 N 块。
