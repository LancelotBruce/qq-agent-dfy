# 群聊动态节奏（group-pacing）

## 功能

按群统计最近 60 秒有多少个不同真人发言，动态缩短等待时间，让机器人在多人讨论时更早收口，避免把四五个人同时说的话压进同一批。

| 最近 60 秒 | 等待 |
| --- | --- |
| 0–2 人 | 25 秒（内核原值） |
| 3 人且 ≥6 条 | 12 秒 |
| 4 人且 ≥8 条 | 8 秒 |
| 5 人以上且 ≥8 条 | 5 秒 |

命中忙时档位后保持 120 秒；之后每 30 秒回落一档，直到回到 25 秒。

## 怎么用

安装后在控制台插件页启用即可，只管群聊，私聊仍走 `wakeDelayMsPrivate`。需要内核提供 `wake.delay` 扩展点；没有这个扩展点时插件自动回落到普通 25 秒等待，不会影响机器人运行。

统计发生在入站观察阶段，即使 `chatter-guard` 已经决定这条消息免回，仍会计入人数和消息数；这样不会因为“连续水聊免回”漏掉正在发言的人。

建议配合 `group-manner`：`group-pacing` 决定“这一批等多久”，`group-manner` 决定“这一轮该不该开口”。
