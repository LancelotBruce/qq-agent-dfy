# 调试编年史（dfy-chronicle）

把《本机调试编年史》装进机器人，让它在聊天里查得到 2026-10-27 → 11-27 的调试过程。

## 功能

- 12 段主线、10 起有档案的事故、8 组可复核数字、7 条定型口径、6 个未决项、3 类证据出处。
- **不注入提示词**：同样的要点已写进人设细节档案的「调试档案」分类，模型问到旧事故/旧版本时按需走 `query_persona_detail`；本插件只在需要全文或发图时调用，平时不占常驻上下文。
- 纯本地只读：不联网、不改人设、不写记忆、不动宿主配置。

## 怎么用

聊天指令：

- `/编年史`：总览（12 段时间轴 + 10 起事故）
- `/编年史 OneBot`：按关键词查，支持日期、插件名、报错、现象、指标

模型工具：

- `dfy-chronicle__chronicle_overview`：总览
- `dfy-chronicle__chronicle_search`：按关键词搜（默认 5 条）
- `dfy-chronicle__chronicle_get`：按编号取全文（P1~P12 / I1~I10 / N1~N8 / R1~R7 / E1~E3 / O1~O6 / OVERVIEW）
- `dfy-chronicle__chronicle_send_image`：把整页长图发到当前会话

## 数据与更新

- 结构化数据：`assets/chronicle.json`
- 长图：`assets/chronicle.png`
- 重新生成：改完 `<工作目录>\调试编年史.html` 后执行 `python tools/build-data.py`，再在控制台热重载 `dfy-chronicle`。
